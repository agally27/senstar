### HIGH

**H1 — CI was red on the pushed commits: `pnpm format` fails. (FIXED)**
`apps/web/next-env.d.ts` is committed with double-quoted imports; the repo's Prettier config requires single quotes. `.github/workflows/ci.yml` runs `pnpm format` as a blocking step before tests and build, so every run on the three pushed commits would have failed there.

`prettier --write` is not a durable fix: the file is regenerated by Next.js on every build (confirmed — `pnpm build` rewrote it with double quotes), and the file's own header says it should not be edited. Fixed by adding `**/next-env.d.ts` to `.prettierignore`, matching the existing precedent in `eslint.config.mjs`, which already ignores the same path for the same reason.

This contradicts the handover's "lint/format clean". Format was never clean.
